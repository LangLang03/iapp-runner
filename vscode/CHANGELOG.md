# iApp Language Support - Changelog

## [1.0.0] - 2024-01-01

### Added
- Initial release
- Syntax highlighting for iApp language
- LSP client integration with Java-based language server
- Code completion support
- Error diagnostics
- Hover information
- Signature help
- Document symbols
- Language configuration (brackets, comments, indentation)
- Commands for restarting server and showing output

### Features
- Support for `.iyu`, `.myu`, `.mjava`, `.iapp` file extensions
- Chinese variable name support
- Block comment syntax (`/. ./`)
- Variable scope highlighting (`s`, `ss`, `sss`)
- Control flow keyword highlighting (`f`, `w`, `for`, etc.)
